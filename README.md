# Proyecto Final de Compiladores

Analizador léxico y sintáctico desarrollado en Java utilizando JFlex y CUP.

## Características

- Análisis léxico
- Análisis sintáctico
- Validación de expresiones
- Detección de errores léxicos y sintácticos
- Interfaz gráfica con Java Swing

## Tecnologías utilizadas

- Java
- JFlex
- CUP
- Swing
- NetBeans

## Componentes principales

- `Lexer.flex` → definición léxica
- `LexerCup.flex` → lexer para CUP
- `Sintax.cup` → gramática sintáctica
- `Sintax.java` → parser generado
- `Tokens.java` → definición de tokens
- `FrmPrincipal.java` → interfaz principal

## Objetivo del proyecto

Simular el funcionamiento básico de un compilador mediante el reconocimiento de tokens y validación sintáctica de entradas.
